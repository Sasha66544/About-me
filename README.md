### 👨‍💻 Обо мне

Я — начинающий QA-инженер с горящими глазами и острым взглядом на детали. Моя главная суперсила — находить баги там, где другие видят работающий продукт. 

Мне нравится разбираться в том, как устроены приложения «под капотом»: я изучаю клиент-серверное взаимодействие, умею читать логи и работать с API через Postman. Сейчас активно ищу стажировку, чтобы применить свои знания на реальных проектах, научиться работать в команде разработки и вырасти до инженера автоматизации.

- 🎯 **Основной фокус:** Ручное функциональное, регрессионное и интеграционное тестирование.
- 🛠️ **Инструменты:** Postman, Swagger, DevTools, DBeaver, TestRail, Qase.io, Jira/YouTrack.
- 💾 **Базы данных:** Написание простых SELECT-запросов (SQL) для проверки данных.
- 🐍 **В планах на рост:** Изучение Python + Pytest для автоматизации UI и API тестов.
